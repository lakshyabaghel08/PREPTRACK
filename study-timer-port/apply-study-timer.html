Route 1 · Upload the files through GitHub's web UI

GitHub's web upload stops at 100 files and 25 MB per file, and it cannot apply a .patch. It can upload 21 small files at once.

  1. (147 KB — 21 files, byte-identical to the commit).
  2. Unzip it on your computer. You get the repo's folder structure with the changed and new files in place.
  3. On GitHub, open github.com/lakshyabaghel08/MyMPPSC → Add file ▾ → Upload files, drag the contents of the unzipped folder in, and commit to a new branch such as feat/study-timer.

GitHub keeps the folder paths when you drag a folder, so js/ui/views/timer.js lands in the right place. It will overwrite the 12 modified files with identical-purpose edits — which is exactly what the commit does.
